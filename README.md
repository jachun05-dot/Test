# 냥식단 — 아픈 고양이를 위한 사료 성분 계산기

사료 포장지의 성분표를 입력하면 건물 기준(DMB)·100kcal당으로 바꿔서, 고양이의 질환별 권장 범위와 비교해 주는 웹앱입니다.

> 참고용 계산기입니다. 진단과 처방은 반드시 수의사와 상의하세요. 질환별 기준치는 아직 수의사 검토를 받지 않았습니다.

## 기능 (1단계)

- **고양이 프로필**: 체중, 나이, 중성화 여부, 체형점수(BCS), 이상 체중, 급여 목표, 질환(여러 개 선택, 단계·유형 포함)
- **하루 필요 칼로리**: RER = 70 × 체중^0.75에 생애 단계·목표별 계수를 곱해 계산 (감량 시 이상 체중 기준 × 0.8)
- **사료 성분 분석**: 건물 기준 변환, 탄수화물 역산 추정, 칼로리 추정(수정 Atwater 계수), 100kcal당 성분량, 칼로리 구성 비율
- **식단 분석**: 여러 사료를 칼로리 비율 또는 g으로 섞어 먹일 때의 하루 급여량, 한 끼 양, 하루 섭취량(체중 1kg당 포함), 음식으로 먹는 수분, 칼슘:인 비율
- **질환별 판정**: 신장병(IRIS 1–4단계), 당뇨, 하부요로질환(스트루바이트/옥살레이트/FIC), 갑상선항진증, 비만, 저체중, 심장병, 만성 소화기 질환, 간 질환, 췌장염. 기준마다 적정/주의/벗어남으로 표시하고 근거 문헌을 함께 보여줍니다.
- **질환 간 충돌 안내**: 두 질환의 권장 범위가 겹치지 않으면(예: 신장병 단백질 상한 vs 비만 단백질 하한) 알려줍니다.
- **사료 비교**, **급여 기록**, **데이터 백업/복원**
- PWA: 휴대폰 홈 화면에 설치할 수 있고 오프라인에서도 작동합니다.

데이터는 브라우저(localStorage)에만 저장됩니다. 처음 열면 `예시)`로 표시된 가상의 고양이와 사료가 들어 있습니다 (실제 제품 아님).

## 실행

외부 런타임 의존성은 없고, 빌드에 TypeScript만 필요합니다.

```bash
npm install        # typescript 설치
npm run build      # src/ → dist/
npm test           # 계산 엔진 테스트
npx serve .        # http://localhost:3000
```

## 구조

```
src/nutrition/     계산 엔진 (UI와 무관, 앱 확장 시 그대로 재사용)
  nutrients.ts     성분 정의와 단위
  profile.ts       건물 기준, 탄수화물·칼로리 추정, 100kcal당, 식단 합산
  energy.ts        RER/MER, 이상 체중, 필요 수분
  guidelines.ts    질환별 기준치와 근거  ← 수의사 검토 대상
  evaluate.ts      판정, 기본 기준 대체, 질환 간 충돌 감지
src/app/           화면 (프레임워크 없이 TypeScript + DOM)
tests/             계산 엔진 테스트 (node:test)
```

## 기준치에 대해

모든 기준치는 `src/nutrition/guidelines.ts` 한 파일에 모여 있습니다. 근거는 AAFCO 최소 기준, IRIS, AAHA, ACVIM 가이드라인이고, 가이드라인에 숫자가 없는 항목(예: 신장병의 인 상한)은 시판 처방식의 일반적인 성분 범위를 사용했습니다. **서비스를 공개하기 전에 수의사 검토가 필요합니다.**
